# 独立交互演示模块

本包只展示截图中的左侧流程导航、手机样机、右侧说明与重置按钮，包含 A/B 两条路径和当前版本的全部交互。

## 嵌入其他网站

将整个 travel-flow-embed 文件夹上传到目标网站，保持目录结构。在目标页面加入：

```html
<iframe src="/travel-flow-embed/index.html" title="旅行规划交互演示"
  style="display:block;width:100%;height:1200px;border:0"
  loading="lazy"></iframe>
```

可按页面调整高度。手机端内容会纵向排列，可增加高度或保留 iframe 内滚动。不要直接复制 HTML 片段到宿主页面，以免样式相互影响。

同目录 embed-example.html 提供完整嵌入示例。无需安装依赖或构建。通过 HTTP/HTTPS 访问，避免直接双击 index.html 的 file 协议影响嵌套页面联动。不要设置限制脚本或同源访问的 iframe sandbox。

本地预览：在此文件夹运行 node serve.cjs，访问 http://localhost:8945/。

## 交互范围

流程切换、步骤导航与说明同步、生成动画、暂停修改和继续、非预设文字回复与恢复、输入框状态、图片放大滑动、思考折叠、地图放大返回、日期和总览切换、导航进入地图选择、演示提示与重置均保留。

当前仍是原型演示：AI 生成使用预设数据；语音识别和真实地图跳转未接入。素材全部在本地 assets 和 travel-flow/assets 中，无需临时 Figma 链接。
